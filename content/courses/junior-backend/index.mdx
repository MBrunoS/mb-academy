O projeto da trilha back-end é a API que sustenta o mesmo **MB Finanças** construído no curso Front-end. As trilhas compartilham o produto e o contrato HTTP, mas continuam independentes: você recebe testes externos e um cliente React de referência para validar sua API sem depender de outro aluno.

## Resultado final

Você entregará uma API REST em NestJS e TypeScript com PostgreSQL, Prisma, autenticação JWT, isolamento por usuário, CRUD de receitas e despesas, filtros, paginação, resumo financeiro, Swagger e testes.

O projeto cresce em seis sprints:

1. API NestJS em memória;
2. persistência PostgreSQL;
3. identidade e autorização;
4. contrato completo e documentação;
5. testes automatizados;
6. integração com um cliente real e deploy.

Cada sprint termina com comportamento executável, critérios de aceite e um checkpoint de recuperação. O objetivo não é apenas “ter endpoints”: é construir uma fronteira previsível que qualquer cliente compatível consiga usar.

## Limites

O projeto obrigatório não inclui refresh token, OAuth, papéis administrativos, categorias personalizadas, recorrência ou múltiplas moedas. Esses recursos aumentariam o número de conceitos simultâneos sem melhorar a comprovação das competências centrais de uma vaga júnior.

Enquanto as aulas teóricas completas da trilha estão em preparação, estas páginas funcionam como a especificação oficial do projeto e como referência para a futura escrita dos capítulos.
