Agora que você já conhece os fundamentos da programação com JavaScript, é hora de configurar seu **ambiente local de desenvolvimento**. Isso significa preparar o seu computador com as ferramentas necessárias para criar, testar e evoluir projetos reais de forma fluida e organizada.

Se até agora você experimentou JavaScript em plataformas online, chegou o momento de montar seu espaço de trabalho profissional: com editor de código, terminal, interpretador da linguagem, ferramentas auxiliares e, se estiver no Windows, até mesmo um ambiente Linux virtualizado.

Esse processo pode parecer técnico à primeira vista, mas vamos abordar **passo a passo, com calma e propósito**, para que você entenda o valor de cada ferramenta — e não apenas execute comandos.

## Por que configurar um ambiente local?

Programar localmente é como montar sua própria oficina. Você tem liberdade para instalar o que quiser, organizar seus arquivos como preferir, testar com tranquilidade e integrar ferramentas que aumentam sua produtividade.

Além disso, com o ambiente configurado:

- Você **não depende de conexão com a internet** para programar.
- Pode salvar seus projetos em pastas organizadas, com controle de versões via Git.
- Ganha autonomia para usar ferramentas modernas, como Node.js, npm e bundlers.
- Aprende a usar o **terminal**, um recurso essencial na rotina de qualquer desenvolvedor.
- E se estiver no Windows, pode simular um ambiente Linux usando o **WSL**, tornando seu sistema mais parecido com o de servidores e da maioria dos ambientes de produção.

## Terminal: o ponto de encontro das ferramentas

O **terminal** (também chamado de linha de comando, shell ou console) é uma ferramenta fundamental para desenvolvedores. Ele permite que você **execute comandos diretamente no sistema operacional**, sem interface gráfica, de forma rápida e poderosa.

Algumas tarefas comuns feitas via terminal:

- Navegar entre pastas do projeto
- Criar, renomear ou excluir arquivos
- Instalar bibliotecas com npm
- Inicializar repositórios Git
- Rodar servidores locais de desenvolvimento

Você não precisa ser um especialista em terminal agora, mas quanto antes se familiarizar com ele, melhor. No início, você usará comandos simples — como `cd`, `ls`, `mkdir`, `code .` — mas aos poucos vai perceber que o terminal é um grande aliado.

## E se eu uso Windows? Conheça o WSL

Se você está usando Windows, pode trabalhar com o terminal padrão (Prompt de Comando ou PowerShell), mas há uma alternativa muito mais poderosa e próxima da experiência dos profissionais: o **WSL (Windows Subsystem for Linux)**.

O WSL é uma funcionalidade do Windows que permite **executar um ambiente Linux completo dentro do Windows**, com acesso ao terminal Linux, comandos Unix, gerenciadores de pacotes, arquivos e integração com ferramentas modernas.

Por que isso é útil?

- A maioria dos tutoriais, ferramentas e ambientes profissionais usa Linux ou macOS.
- Com o WSL, você pode seguir essas instruções sem precisar adaptar comandos.
- Você terá acesso a um terminal Unix real, com ferramentas como `bash`, `apt`, `curl`, `git`, `nvm` e muito mais.
- É possível abrir o VS Code dentro do WSL com todos os arquivos sincronizados.

Você não precisa instalar o WSL agora, mas se estiver no Windows e quiser um ambiente de desenvolvimento **mais fluido, profissional e alinhado com o mercado**, vale muito a pena.

## O que vamos instalar nas próximas etapas?

Para montar um ambiente moderno e eficiente, vamos instalar:

1. **Visual Studio Code (VS Code)** – editor leve, poderoso e extensível.
2. **Node.js e npm** – para executar JavaScript fora do navegador e instalar pacotes.
3. **Extensões e ajustes no VS Code** – para ganhar produtividade.
4. **Git** – para versionar seus projetos (no próximo capítulo).

Você aprenderá o papel de cada ferramenta, como instalá-la corretamente e como integrá-la ao seu fluxo de trabalho de forma simples.

Na próxima seção, vamos explorar os **editores de código**, com foco no VS Code — explicando por que ele é tão usado por desenvolvedores de todas as áreas, como instalá-lo e como começar a usá-lo com eficiência.
