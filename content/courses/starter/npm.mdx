### Verificando a instalação

Independente do sistema operacional, você pode verificar se o Node.js e o NPM foram instalados corretamente executando:
```bash
node --version
npm --version
```

Se tudo estiver correto, você verá as versões do Node.js e do NPM instalados.

<Callout>
Recomendamos sempre usar a versão LTS (Long Term Support) do Node.js, que é mais estável e tem suporte de longo prazo.
</Callout>

Se o Git e o GitHub ajudam você a **organizar e compartilhar seus projetos**, o **NPM** é o que permite **potencializar seus projetos com ferramentas externas**.

O **NPM (Node Package Manager)** é o **gerenciador de pacotes do Node.js**. Ele é uma ferramenta que permite:

- Instalar bibliotecas e ferramentas prontas
- Gerenciar dependências (softwares que seu projeto precisa para funcionar)
- Executar scripts de automação (como rodar um servidor local ou testes)
- Compartilhar pacotes criados por você com o mundo (ou só com seu time)

Na prática, o NPM permite que você use milhares de pacotes desenvolvidos pela comunidade para **acelerar seu trabalho** e **evitar reinventar a roda**.

## O que são pacotes?

Um **pacote** no contexto do NPM é basicamente **um conjunto de arquivos JavaScript agrupados e distribuídos com um nome e uma versão**. Pode ser uma biblioteca, um framework, uma ferramenta de build, um estilo CSS, ou qualquer outro recurso que seu projeto possa usar.

Exemplos populares de pacotes:

- `react` - biblioteca para construir interfaces
- `express` - framework para criar APIs e servidores
- `axios` - cliente HTTP para buscar dados
- `eslint` - ferramenta para encontrar erros no código
- `vite`, `webpack` - empacotadores de projetos

Cada pacote está registrado no repositório central do NPM, que você pode explorar aqui:

🔗 [https://www.npmjs.com](https://www.npmjs.com/)

## Como instalar um pacote

Após ter o Node.js instalado, você pode usar o NPM diretamente no terminal. Para instalar um pacote localmente no seu projeto, use:

```bash
npm install nome-do-pacote
```

Por exemplo:

```bash
npm install axios
```

Isso cria uma pasta chamada `node_modules` (com os arquivos da dependência) e atualiza ou cria o arquivo `package.json` com a lista de dependências.

## O que é o `package.json`?

O `package.json` é o **coração de um projeto Node.js**. Ele contém as informações básicas do projeto:

- Nome, versão e descrição
- Lista de dependências
- Scripts customizados
- Licença, autor e outras configurações

Você pode criar um `package.json` do zero com:

```bash
npm init
```

O NPM vai fazer algumas perguntas (nome do projeto, versão, etc.) e gerar o arquivo para você. Se quiser pular as perguntas e aceitar os padrões:

```bash
npm init -y
```

## Instalando Dependências

Existem dois tipos de dependências:

1.  **`dependencies`**: Pacotes que seu projeto precisa para **funcionar em produção** (ex: um framework web).
2.  **`devDependencies`**: Pacotes usados apenas durante o **desenvolvimento** (ex: ferramentas de teste, compiladores).

### Instalando o TypeScript e o `ts-node`

Para nossos projetos, vamos precisar de duas ferramentas essenciais como dependências de desenvolvimento:

-   `typescript`: O compilador do TypeScript.
-   `ts-node`: Uma ferramenta que permite executar arquivos TypeScript diretamente, sem a etapa manual de compilação.

Instalamos ambos com o seguinte comando:

```bash
npm install typescript ts-node --save-dev
```

O `--save-dev` (ou `-D`) informa ao NPM que estes são pacotes para o ambiente de desenvolvimento. Após a instalação, eles aparecerão na seção `devDependencies` do seu `package.json`.

## Instalando uma dependência de produção

Se seu projeto precisasse de uma biblioteca para funcionar (por exemplo, `axios`), você a instalaria assim:

```bash
npm install axios
```

Este pacote seria listado em `dependencies`.

## O que é a pasta `node_modules`?

Quando você instala um pacote, o NPM o baixa (junto com suas próprias dependências) para uma pasta chamada `node_modules`. Esta pasta geralmente contém muitos arquivos e **não deve ser enviada para o Git**. Adicione `node_modules/` ao seu arquivo `.gitignore`.

## Instalando dependências de um projeto existente

Quando você baixa um projeto de outra pessoa, ele não vem com a pasta `node_modules`. Para instalar todas as dependências listadas no `package.json`, basta rodar:

```bash
npm install
```

O NPM lerá os campos `dependencies` e `devDependencies` e instalará tudo o que for necessário.

## Scripts personalizados

No `package.json`, você pode definir **scripts personalizados** para rodar comandos com atalhos simples. Por exemplo:

```json
"scripts": {
  "start": "node index.js",
  "dev": "nodemon index.js"
}
```

Agora, no terminal, você pode executar:

```bash
npm start
npm run dev
```
