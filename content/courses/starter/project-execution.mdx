## Revisando o que você usou

Cada conceito do curso aparece neste projeto:

| Conceito | Onde aparece |
|---|---|
| **Interfaces e union types** | `Gasto` e `Categoria` em `tipos.ts` |
| **Classes e encapsulamento** | `RastreadorDeGastos` com propriedades `private` |
| **Módulos** | `import`/`export` entre os três arquivos |
| **Array methods** | `push`, `filter`, `map`, `reduce`, `forEach` |
| **Tratamento de erros** | `throw` em `adicionarGasto`, `try/catch` em `index.ts` |
| **TypeScript strictness** | O compilador impede categorias inválidas em tempo de compilação |

## Desafios para evoluir

Este projeto tem bastante espaço para crescer. Cada desafio abaixo é uma funcionalidade real que tornaria o projeto mais valioso no portfólio.

### Desafio 1: Definir um orçamento mensal

Adicione um método `definirOrcamento(valor: number): void` e um método `verificarOrcamento(): void` que exibe quanto do orçamento já foi usado e quanto resta.

### Desafio 2: Gasto mais caro por categoria

Crie um método `gastoDominantePorCategoria(): void` que, para cada categoria com gastos, exibe o item de maior valor. Use `Math.max` e `filter`.

### Desafio 3: Persistência em arquivo

Atualmente os dados são perdidos quando o programa termina. Adicione:
- `salvarGastos()`: converte o array para JSON e grava em `gastos.json` usando o módulo `fs` do Node.js
- `carregarGastos()`: lê o arquivo na inicialização da classe e restaura os dados

Este é o desafio mais complexo, mas torna a aplicação genuinamente útil.

### Desafio 4: Remover um gasto

Implemente `removerGasto(id: number): void` que encontra o gasto pelo ID e o remove do array. Use `filter` — o mesmo padrão que você viu no curso.

### Desafio 5 (aberto): Torne-o seu

Adicione algo que faça sentido para você — metas por categoria, alertas de gastos excessivos, exportação para CSV, ou uma categoria personalizada. Esse tipo de personalização é o que faz um projeto de portfólio se destacar.

## Colocando no portfólio

Para publicar este projeto no GitHub:

1. Inicie o repositório Git dentro da pasta do projeto:
   ```bash
   git init
   git add .
   git commit -m "feat: rastreador de gastos pessoais em TypeScript"
   ```
2. Crie um repositório no GitHub e faça o push
3. Escreva um `README.md` descrevendo o que o projeto faz, como rodar e quais conceitos ele demonstra

Um projeto bem documentado conta mais do que dez projetos sem descrição.
