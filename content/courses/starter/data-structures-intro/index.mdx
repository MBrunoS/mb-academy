Conforme seu conhecimento em programação evolui, você vai perceber que uma parte fundamental de todo programa é lidar com **informações**. Seja um sistema de cadastro de clientes, um jogo, uma loja virtual ou uma rede social, todos eles têm algo em comum: precisam **armazenar, organizar, acessar e manipular dados de forma eficiente**.

É aqui que entra um dos tópicos mais importantes da ciência da computação e do desenvolvimento de software: as **estruturas de dados**.

## O que são estruturas de dados?

Estruturas de dados são formas organizadas de **armazenar informações na memória do computador** para que possam ser usadas com eficiência. Elas definem **como os dados são agrupados, acessados e manipulados** — e, dependendo da estrutura escolhida, podemos realizar operações como busca, inserção, remoção, ordenação e iteração com mais facilidade (ou mais dificuldade).

Em termos simples, uma estrutura de dados é uma **forma de organizar valores** para que possamos trabalhar com eles de maneira coerente.

Por exemplo:

- Uma **lista de tarefas** pode ser representada como um **array** (lista ordenada).
- As **informações de um usuário** (nome, e-mail, idade, endereço) podem ser armazenadas em um **objeto**, agrupando todas as propriedades em uma única estrutura.
- Um **histórico de navegação** pode ser armazenado como uma **pilha**, onde o último site acessado é o primeiro a ser removido.
- Uma **fila de impressão** pode ser representada com uma **fila (queue)**, onde o primeiro a entrar é o primeiro a sair.

Neste curso, vamos começar pelas **estruturas de dados mais comuns no JavaScript**: os **arrays** e os **objetos**. Elas são utilizadas em praticamente todos os sistemas e aplicações, e representam a base para entender estruturas mais complexas no futuro, como listas encadeadas, árvores, conjuntos, mapas, pilhas e filas.

## Por que aprender estruturas de dados agora?

Você já aprendeu a usar **variáveis**, **condições**, **funções** e **loops**, e provavelmente já percebeu que trabalhar com dados isolados (como `let nome = "Lucas"`) funciona bem só até certo ponto. Mas e se você tivesse que guardar 100 nomes diferentes? Ou representar todas as informações de uma pessoa? Ou fazer um cálculo envolvendo uma lista inteira de produtos?

Se tentasse resolver isso com uma variável para cada dado, seu código ficaria rapidamente caótico e inviável. Com estruturas de dados, podemos **reunir todos esses valores dentro de uma única variável**, e ainda organizar essas informações de forma **semântica e lógica**.

Estruturas de dados são o que dão **forma** às suas informações. Elas permitem que você pare de pensar apenas em valores individuais, e comece a pensar em **coleções, conjuntos, agrupamentos e entidades**. Esse é um passo essencial para se tornar um desenvolvedor profissional.

## O que você vai aprender a seguir

Nas próximas seções, vamos nos aprofundar nas duas estruturas mais essenciais do JavaScript:

- **Arrays**, que representam listas ordenadas e nos permitem agrupar valores em sequência, acessar por índice, percorrer com loops e aplicar métodos úteis para manipulação de dados.
- **Objetos**, que são estruturas não ordenadas, baseadas em pares `chave: valor`, perfeitas para representar entidades do mundo real, como um usuário, um produto, um endereço ou qualquer outro item com propriedades distintas.

Essas estruturas serão a base para:

- Trabalhar com dados dinâmicos
- Interagir com APIs e armazenar as respostas
- Criar componentes de interface que se adaptam a dados externos
- Construir modelos de informação complexos e reutilizáveis

Ao dominar arrays e objetos, você estará pronto para lidar com quase todas as situações comuns de armazenamento e manipulação de dados em aplicações web — tanto no front-end quanto no back-end.

Vamos começar por arrays, a estrutura de dados mais acessível e presente em praticamente todos os projetos com JavaScript.
