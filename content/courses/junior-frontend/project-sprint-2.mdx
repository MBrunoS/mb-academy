## História de usuário

> Como pessoa usuária, quero cadastrar, editar, remover e filtrar transações e ver os totais atualizados sem recarregar a página.

## Modelo inicial

Use os nomes definidos pelo contrato do projeto:

```ts
type TransactionType = "income" | "expense";

interface Transaction {
  id: string;
  type: TransactionType;
  description: string;
  amountInCents: number;
  category: string;
  occurredAt: string;
}
```

Mantenha `amountInCents` como inteiro. Converta o texto digitado apenas na fronteira do formulário e formate centavos somente ao renderizar.

## Entrega

- Separe `state.ts`, `rules.ts`, `render.ts` e `main.ts`.
- Implemente criar, iniciar edição, confirmar edição e remover com confirmação.
- Recalcule receitas, despesas e saldo depois de cada alteração.
- Combine filtros de tipo, categoria e intervalo de datas.
- Use delegação de eventos na lista, com o `id` em `data-transaction-id`.
- Mostre erros de validação perto dos campos e mova o foco para o primeiro inválido.
- Persista o array no `localStorage`, tratando conteúdo ausente ou corrompido.

## Casos que precisam funcionar

Descrição vazia, valor zero, valor negativo e data ausente não podem ser salvos. Remover uma transação filtrada deve removê-la do estado original, não apenas da lista visível. Uma edição cancelada não pode alterar os dados. Se nenhum item corresponder aos filtros, mostre estado vazio sem apagar o formulário.

Extraia e teste manualmente as funções puras `calculateSummary`, `filterTransactions`, `parseAmountToCents` e `formatCents`. Não faça requisições ainda: o objetivo desta sprint é entender o ciclo estado → regra → renderização.
