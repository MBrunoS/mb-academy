# Publicação dos materiais

Os manifestos `frontend.json` e `backend.json` registram as tags públicas dos
pacotes de cada sprint.

1. `sprint-N-materials` contém o starter, o enunciado e o kit compartilhado;
2. a tag é imutável e possui uma release com o mesmo nome;
3. correções posteriores entram no branch `main` e em uma nova versão, sem mover
   silenciosamente uma tag já usada por alunos;
4. uma solução progressiva só recebe tag própria depois que a implementação e a
   aula correspondente estiverem completas e validadas;
5. a API e o cliente de referência servem para integração, não como código que o
   aluno deve copiar para a sua entrega.

Os repositórios públicos são `MBrunoS/junior-frontend-financas` e
`MBrunoS/junior-backend-financas`.
